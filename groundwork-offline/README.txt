Groundwork — offline copy

1. Put this folder on any HTTPS web host (GitHub Pages, Netlify, Cloudflare Pages). It is plain files; no server code.
2. Open the address in Safari on your iPhone or iPad while you have internet. Wait for "Saved on this device".
3. Share button → Add to Home Screen. Open Groundwork from the Home Screen icon from then on.
   It opens, draws, walks through and saves with no connection.

Projects saved in the Home Screen app are kept separately from projects you made in Safari or in the
claude.ai link. To move one: Menu → Backup → Copy project text, then paste it into Restore in the other copy.
When you publish a new version to the same address, the app downloads it the next time it is online and
offers to reload.
